|---|---|

## 1. 스토리

### 1-1. 설정
- 배경은 연합군 **출격 기지 행성의 야외 훈련장(협곡)**. 하이브 근원 행성으로 떠나기 직전이다.
- 플레이어(전투 사이보그)는 출격 자격을 얻으려고 **기본 전투 테스트**를 받는다.
- 테스트 과목을 하나씩 통과할 때마다 다음 구역 차단막이 열린다. 마지막 과목까지 마치면 협곡 끝의 **비행시설(발진 기지) 게이트**가 열리고, 그 안으로 들어가면 출격한다.
- 안내자는 **시험 감독관 AI "오퍼레이터"** 다. 군대식으로 짧고 명확하게 말한다. 유머는 **한두 군데에 한 줄 정도만** 가볍게 넣는다 (진행을 방해하지 않는 선).
- 몬스터는 연구소가 포획한 **하이브 표본**이다. 시험용으로 우리에서 풀어 준다. 본편에 나올 몬스터를 미리 보여 주는 역할도 한다.

### 1-2. 맵에 있는 것을 스토리로 다시 설명
| 맵에 있는 것 (`TutorialMapBuilder`) | v2 스토리 |
|---|---|
| 시작 지점 옆, 협곡 벽에 처박힌 추락선 `Spaceship_Broken` | "**지난 착륙 시험에서 실패한 기체**. 교육용으로 남겨 뒀다." 본편 인트로의 격추를 넌지시 알리는 복선 |
| 잔해 협곡 (좁은 길) | 기동 훈련로. 질주·구르기 구간 |
| 넓은 조우 공간 + 엄폐물 | 표본 사격장. 표본을 풀어 주는 곳 |
| 보급 포드 공터 (착륙판·유도등) | 보급 투하 훈련장 |
| 전초기지 외벽 + 게이트 `Wall1_Gate` | **비행시설 게이트**. 통과하면 출격 |

### 1-3. 본편과 이어지는 부분
| 튜토리얼 | 본편 |
|---|---|
| 테스트를 통과하고 비행선에 탑승 | 인트로 크롤: 대기권에 들어가다 격추 → 불시착 |
| 추락선 ("착륙 시험에서 실패한 기체") | 실제로 플레이어가 추락한다 |
| 보급 투하를 받는 법 | 같은 방식으로 궤도 보급 포드를 받는다 |
| 강화 체험 | 스테이지 클리어 후 강화 화면 |

## 2. 단계 구성과 맵 배치

```
 z=212  [⑨ 비행시설 게이트]  Wall1_Gate → 진입 → IntroCrawl
          │
 z≈185  [⑧ 장비 정비 단말기]  강화 체험                   ← 새 마커
          │
 z=152  [⑥⑦ 보급 포드 공터]   보급 투하 → 보급 무기 시험
          │
 z=110  [③④⑤ 표본 사격장]    사격·처치 보상 → 수류탄 → 힐팩
          │
 z=60   [② 기동 훈련로]       질주 · 구르기 (레이저 차단막)
          │
 z=10   [① 출발점]           이동 (추락선 복선)
```

| # | 단계 | 플레이어가 하는 일 | 완료 조건 | 화면 안내 |
|---|---|---|---|---|
| 1 | 이동 | WASD 로 표시 지점까지 이동 | 목표 지점 트리거에 들어감 | 시선 조작 |
| 2 | 달리기·구르기 | Shift 질주 2초 → Ctrl 구르기로 레이저 차단막 2개 통과 | 질주를 모두 합쳐 2초 + `RollStarted` 2회 | **스태미나 바**: 쓰면 줄고, 바닥나면 질주·구르기를 못 하고, 가만히 있으면 다시 찬다 |
| 3 | 조준·사격 | 우클릭으로 조준 → 풀려난 표본 3마리 처치 | 조준 1회 + 처치 3 (`MonsterDiedEvent`) | 처치할 때마다 **"+N 생체 자원"** 표시. "강화에 쓰는 재화" 설명 |
| 4 | 수류탄 | G 로 뭉쳐 나온 표본 무리에 던진다 | `GrenadeExplodedEvent` 1회 + 무리 전멸 | 수류탄 남은 개수 표시 위치 |
| 5 | 힐팩 | 훈련용 충격으로 HP 가 깎인 뒤 V 로 회복 | `PlayerItems.HealEnded` | 3초에 걸쳐 회복되고, 그동안은 움직임이 제한된다 |
| 6 | 보급 획득 | 빛기둥을 따라가 무기 보급 상자에서 F | `SupplyCollectedEvent` (무기 상자) | 빛기둥이 보급 위치, 상자 색으로 종류 구분 |
| 7 | 보급 무기 | 4번 칸 보급 무기로 표본 무리 처치 | 보급 무기 탄을 다 씀 (`SupplyWeaponChangedEvent.Depleted`) 또는 무리 전멸 | **보급 무기 특징**: 4번 칸 전용 · 1회용(탄을 다 쓰면 사라지고 들던 무기로 돌아감) · 탄창 보충 안 됨 · 무기별 활용법(기존 보급 카드) |
| 8 | 강화 체험 | 단말기에서 F → 강화 화면에서 1개 구매 → 닫기 | `UpgradePurchasedEvent` → `RewardSelectionFinishedEvent` | 생체 자원으로 강화한다 (3장) |
| 9 | 비행시설 진입 | 게이트 안으로 걸어 들어간다 | 게이트 트리거 | 페이드아웃 → `IntroCrawl` |

공통 규칙
- **목표 패널(오른쪽 위)**, **오퍼레이터 자막(아래, 타자기 효과 + 음성)**, **키 배지**로 안내한다. 키 이름은 옵션 화면과 같은 출처(`KeyGuideList`)에서 가져와 표기를 맞춘다.
- 20초 동안 진행이 없으면 힌트를 한 번 더 띄운다.
- 구역 사이에는 **레이저 차단막**(`TutorialGate`)을 둔다. 과목을 통과하면 열려서 동선이 한 방향으로만 이어진다.

## 3. 강화 체험 — 가벼운 유머

목적은 본편 강화 화면을 실제로 한 번 써 보게 하는 것이다. 설명 위주로 가고, 유머는 한 줄 정도만 곁들인다.

| 순서 | 연출 |
|---|---|
| 단말기 접근 | 오퍼레이터: "장비 정비 단말기다. 방금 회수한 생체 자원으로 장비를 개조할 수 있다. 하나만 골라라." |
| 화면 열림 | **실제 강화 화면**(`UpgradeScreen`)이 열린다 |
| 구매 | 오퍼레이터: "좋은 선택이다." |
| 닫기 | 오퍼레이터: "이번 개조는 **테스트용**이다. 출격 전에 반납된다." → 튜토리얼이 끝날 때 강화·재화를 초기화하는 처리를 자연스럽게 설명한다 |
| 재화가 모자랄 때 | 생체 자원이 강화 1회 값보다 적으면 모자란 만큼 채워 준다: "부족한 만큼은 훈련 예산에서 지원한다." |

- 강화 화면 여는 법: 기존 테스터와 같은 방식이다 (`GameStateChangedEvent(→Reward)` 발행, 끝나면 `RewardSelectionFinishedEvent`).
- **주의:** 강화 시스템 개편(BL-030, 무작위 3장 상점·리롤)이 다른 브랜치에서 진행 중이다. 튜토리얼은 강화 화면을 **여는 방법(이벤트)** 에만 의존하고, 화면 내용(카드 구성)에는 의존하지 않는다. 개편이 끝나도 튜토리얼 코드는 바꿀 필요가 없다.

## 5. 무기 칸이 비어 있을 때 경고 (튜토리얼과 별개 기능)

| 위치 | 언제 | 표시 | 막는가 |
|---|---|---|---|
| **무기 선택 화면** (`LoadoutPanel`, 출발 전·스테이지 사이) | 2·3번 칸 중 빈 칸이 있는데, 채울 수 있는 해금 무기가 남아 있을 때 | [출발] 버튼 위 경고 문구: "⚠ 비어 있는 무기 칸이 있습니다 — 그대로 출발하면 그 칸은 사용할 수 없습니다" | 막지 않음 (경고만) |
| **게임 중** (숫자 키 1~4) | 빈 칸 번호를 눌렀을 때 | 화면 중앙 아래 짧은 토스트: "N번 칸이 비어 있습니다" (4번은 "보급 무기 없음 — 보급 상자에서 획득") | — |

- 해금 전이라 채울 무기가 없을 때는 무기 선택 화면에 경고를 띄우지 않는다.
- 휠로 교체할 때는 빈 칸을 원래 자동으로 건너뛰므로 경고하지 않는다.

## 6. 통신 설계 (기준 v0.1)

| 통신 | 방식 | 이유 |
|---|---|---|
| 단계 → 플레이어 상태 읽기 (질주 중·조준 중·위치) | **직접 참조로 매 프레임 확인** | 가까운 객체의 지금 상태값이고, 따로 알리는 이벤트가 없다 |
| 구르기 · 회복 완료 | **객체 C# event** (`PlayerController.RollStarted`, `PlayerItems.HealEnded`) | 이미 있는 가까운 객체 이벤트 |
| 처치 · 수류탄 폭발 · 보급 획득 · 보급 무기 소진 · 재화 변화 · 강화 구매 | **기존 EventBus 구독** | 이미 발행되는 전역 사실. **새 이벤트를 만들지 않는다** |
| 표본 소환 | **직접 호출** `IMonsterFactory.Spawn` | 요청하고, 결과(생성된 몬스터)를 받아야 한다 |
| 보급 투하 | **직접 호출** `SupplyDropper.Drop(def)` + 낙하 위치는 튜토리얼이 구현한 `ISpawnZoneProvider` 를 등록 | 위치 지정은 기존 계약으로 해결하므로 보급 코드를 고치지 않는다 |
| 수류탄·힐팩 지급, 훈련용 피해 | **직접 호출** (`IItemUser`, `IDamageable`) | 요청 |
| 강화 화면 열기/닫힘 | **기존 EventBus** (`GameStateChangedEvent` 발행 / `RewardSelectionFinishedEvent` 구독) | 강화 화면이 이미 이 신호로 동작한다 |
| 튜토리얼 진행 상황 | **전역 이벤트를 만들지 않는다** | 튜토리얼 밖에 받을 쪽이 없다 (미래 구독자용 버스 금지) |
| Director → 튜토리얼 HUD·음성 | **직접 참조** | 같은 씬 안이고, 순서와 내용을 Director 가 정한다 |
| 게임 중 빈 칸 토스트 | **직접 호출 또는 `GunSlot` 의 C# event** (구현할 때 둘 중 하나로 정함) | 가까운 객체 관찰. 전역으로 알릴 필요가 없다 |

## 7. 데이터 설계 (기준 v0.1)

| 데이터 | 위치 | 이유 |
|---|---|---|
| 단계별 안내 문구 · 목표 문구 · 힌트 · 음성 키 | `TutorialScript` ScriptableObject (`IntroCrawlText` 와 같은 방식) | 시나리오 담당이 인스펙터에서 고친다. 행이 반복되는 표 구조가 아니다 |
| 단계별 목표 수치(처치 수 · 질주 초 · 구르기 횟수) · 소환할 몬스터 ID · 투하할 보급 ID | 같은 `TutorialScript` | 문구와 한 묶음으로 조정한다. 기준값을 한 곳에만 둔다 |
| 음성 파일 | **기존 SoundTable** 에 키로 등록 (`vo_tutorial_01` …) | 기존 사운드 경로(볼륨·덕킹)를 그대로 쓴다 |
| 몬스터 능력치 · 처치 보상 · 보급 무기 설명 · 강화 항목 | **기존 테이블 그대로** | 튜토리얼용 복제값을 두지 않는다 |
| 소환 위치 · 목표 지점 · 차단막 · 단말기 · 게이트 트리거 | 씬 오브젝트 (`TutorialMapBuilder` 마커) | 배치와 콜라이더 |
| 힌트 대기 시간(20초) · 힐팩 단계 피해 비율 | 코드 상수 | 구현 상수 |
| 튜토리얼 완료 기록 `Tutorial.Done` | PlayerPrefs | 런타임 현재 값 |

## 8. 한국어 음성 안내

**가능하다.** 확인용으로 Windows 내장 한국어 음성 "Heami" 로 시작 대사 샘플 1개를 만들어 봤다.
**음성 소스는 담당자(pinkshield)가 직접 찾아 정한다.** 아래 표는 참고용 후보다.

| 방식 (참고 후보) | 품질 | 비용·조건 | 비고 |
|---|---|---|---|
| A. Windows 내장 TTS (Heami) | 기계음 느낌이 있다 | 무료 · 오프라인 · 추가 설치 없음 | 바로 만들 수 있다. 에디터 메뉴로 대사 → wav 를 한꺼번에 만든다 |
| B. 외부 AI 음성 (네이버 클로바 보이스, 타입캐스트, ElevenLabs 등) | 자연스럽고, 감정·캐릭터 톤을 고를 수 있다 | 대부분 유료 · 계정과 이용 약관 확인 필요 | 대사 문구를 외부 서비스로 보낸다 |
| C. 팀원 녹음 | 가장 자연스럽다 | 녹음 시간 | 무전기 필터를 입히면 오퍼레이터 느낌이 난다 |

- 공통 구조: 대사마다 음성 키를 둔다 → wav 를 SoundTable 에 등록 → 자막이 뜰 때 함께 재생한다. **방식을 바꿔도 파일만 바꾸면 된다.**
- 구현은 **음성 없이도 동작하게** 한다. 음성 키가 비어 있거나 파일이 없으면 자막만 띄운다.
- 음성 소스가 정해지면 대사별 wav 를 받아 SoundTable 에 등록하고, `TutorialScript` 에 키만 적으면 된다. 코드는 바꾸지 않는다.

## 9. 구현 범위

### 9-1. 새로 만드는 것 (`Assets/Scripts/Tutorial/`)
| 클래스 | 역할 |
|---|---|
| `TutorialDirector` | 단계를 순서대로 실행 · 차단막 열기 · 건너뛰기 · 끝날 때 정리 · 씬 전환 |
| `TutorialStep` (추상) + 단계 9개 | 시작 / 매 프레임 / 완료 판정 / 끝 |
| `TutorialScript` (ScriptableObject) | 문구 · 수치 · 음성 키 |
| `TutorialHud` | 목표 패널 · 자막 · 키 배지 · "+N 생체 자원" 표시 |
| `TutorialSpawnZone` | `ISpawnZoneProvider` 구현. 보급 낙하 위치를 마커로 고정한다 |
| `TutorialGate` | 레이저 차단막 (열림 연출 + 콜라이더 끄기) |
| `TutorialTerminal` | `IInteractable` 구현. F 로 강화 화면을 연다 |

### 9-2. 끝날 때 정리 (상태가 본편으로 새지 않게)
- 튜토리얼을 마치거나 건너뛰면 아래를 되돌린다:
  - 재화를 0 으로 (`ICurrencyWallet.ResetTo(0)`)
  - 강화를 전부 초기화 (`IUpgradeState.ResetAll()`)
  - 보급 칸 비우기
  - `Time.timeScale = 1`, 입력 잠금 해제
- 재화·강화 서비스는 씬이 바뀌어도 남아 있는 객체라서 이 정리가 반드시 필요하다.

### 9-3. 기존 코드를 고쳐야 하는 곳 — **담당자 확인 필요**
| 파일 | 담당 | 수정 내용 |
|---|---|---|
| `Scenes/GU/Map/Editor/TutorialMapBuilder.cs` | 맵 | 새 마커 추가 (단계별 차단막 · 단말기 · 표본 우리 · 게이트 트리거) |
| `UI/Loadout/LoadoutPanel.cs` | UI | 빈 칸 경고 문구 (5장) |
| `Weapon/GunSlot.cs` 또는 입력부 (`PlayerController.Input.cs`) | 무기 / 플레이어 | 빈 칸을 눌렀을 때 알림 (5장). `Select` 가 false 를 돌려줄 때 C# event 하나 추가 |
| `UI/MainMenu/MainMenuController.cs` | 메인 메뉴 | 처음이면 튜토리얼로 보내고, [TUTORIAL] 버튼 추가 |
| `ProjectSettings/EditorBuildSettings.asset` | 공통 | `TutorialMap` 씬 등록 |

### 9-4. 작업 순서
1. 맵 마커 보강 + 씬 뼈대 (Director · HUD · Script) + 1~2단계
2. 3~5단계 (표본 소환 · 보상 표시 · 수류탄 · 힐팩)
3. 6~7단계 (보급 투하 · 보급 무기)
4. 8단계 (강화 체험) · 9단계 (게이트 → IntroCrawl) · 건너뛰기 · 정리 처리
5. 음성 재생 연결 (키가 있으면 재생, 없으면 자막만) — 실제 음성 파일은 소스가 정해진 뒤 등록
6. 빈 칸 경고 (무기 선택 화면 + 게임 중)
7. 메인 메뉴 연결 · Build Settings · 플레이 테스트
