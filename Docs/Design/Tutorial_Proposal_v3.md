## 1. 빌드 흐름

```
Test_MainMenu ──GAME START──▶ IntroCrawl ──▶ TutorialMap ──게이트──▶ Monster Player Integration
                                   │
                                   └─ (튜토리얼 완료 기록이 있으면) ──────────▶ Monster Player Integration
```

- 인트로가 끝나면 다음 씬을 고른다.
  - 튜토리얼 완료 기록(`PlayerPrefs "Tutorial.Done"`)이 없으면 `TutorialMap` 으로 간다.
  - 기록이 있으면 바로 게임 씬으로 간다.
- 튜토리얼 안에서 Esc → [튜토리얼 건너뛰기] 를 누르면 바로 게임 씬으로 간다. 이때도 완료로 기록한다.
- 메인 메뉴에 [TUTORIAL] 버튼을 두어 다시 할 수 있게 한다 (인트로 없이 튜토리얼로 바로).
- 씬 전환은 기존 `SceneTransition.LoadAsync` 를 쓴다. `TutorialMap` 을 Build Settings 에 등록한다.

## 2. 스토리 — 불시착 후 기본 전투 테스트

인트로 크롤에서 격추·불시착한 직후부터 이어진다.

- 플레이어(전투 사이보그)가 협곡에 처박힌 **자기 강하선**(`Spaceship_Broken`) 옆에서 깨어난다.
- 궤도 위 모함의 **"오퍼레이터"** 가 무전으로 말한다.
  - "추락 충격으로 전투 시스템이 손상됐을 수 있다. **기본 전투 테스트**를 통과해야 전장 진입을 허가한다."
- 협곡에는 아직 깨어나지 않은 **휴면 상태의 하이브 개체**가 있다. 공격해 오지 않으므로 사격 표적으로 쓴다. 3단계에서 몬스터가 가만히 서 있는 이유다.
- 같은 모함이 궤도에서 보급 포드를 투하해 준다. 본편의 보급 방식과 같다.
- 마지막에 협곡 끝 **전초기지 게이트**를 지나 전장으로 들어간다. 본편 시작이다.

기존 맵의 원래 설정(`MapDesign_SciFiBase.md` 5장: 추락 함선 옆 기상 → 잔해 협곡 → 첫 항체 조우 → 보급 포드 공터 → 전초기지 게이트)과 그대로 맞는다. **맵 흐름을 바꿀 필요가 없다.**

## 3. 단계 구성과 맵 배치 (6단계)

```
 z=212  [⑥ 전초기지 게이트]   통과 → 전장(게임 씬)
          │
 z≈185  [⑤ 강화 구역]         도착하면 강화 화면 자동 → 리롤 → 에픽 확정       ← 새 마커
          │
 z=152  [④ 보급 포드 공터]    상자 2종 투하 → 색 구분 → 회복 팩 → 보급 무기
          │
 z=110  [③ 첫 항체 조우]      휴면 개체 무리 → 수류탄
          │
 z=60   [② 잔해 협곡 끝]      휴면 최약체 3마리 → 조준·사격 → 보상
          │
 z=10~60 [① 추락 지점 → 협곡] 이동 → 질주 → 피해 차단막을 구르기로 통과
```

### ① 이동 · 달리기 · 구르기 (통합)
| 순서 | 플레이어가 하는 일 | 완료 조건 |
|---|---|---|
| 1 | WASD 로 추락선 밖 표시 지점까지 이동 | 목표 지점 트리거 |
| 2 | Shift 로 협곡 길을 질주 (스태미나 바 안내) | 질주 누적 2초 |
| 3 | 길을 막은 **피해 차단막** 2개를 Ctrl 구르기로 통과 | 차단막 2개를 **피해 없이** 통과 |

- **피해 차단막**(`TutorialDamageBarrier`)
  - 레이저처럼 생긴 트리거다. 닿으면 소량 피해(기본 10)를 주고 살짝 밀어낸다.
  - 플레이어는 구르기 직후 잠깐 무적이다(`IsInvulnerable`, 기존 기능). 그래서 **구르며 통과하면 피해가 없고**, 이것을 성공으로 판정한다.
  - 걸어서 닿으면 피해를 받고 힌트가 나온다: "구르는 순간에는 피해를 받지 않는다."
  - 스태미나가 모자라 못 구르면: "스태미나가 차면 다시 시도하라."

### ② 조준 · 사격 · 처치 보상
- 길 끝에 **가장 약한 지상 개체 3마리**가 서 있다. 기본은 `1001 부포모프` (HP 20, 보상 1).
  - 움직이지 않고 공격하지 않는다.
  - 테이블에 있는 대기 울음(`IdleSfxKey`)만 낸다.
- 우클릭 조준 1회 + 3마리 처치로 통과한다.
- 처치할 때마다 **"+N 생체 자원"** 이 뜨고, "강화에 쓰는 재화"라고 설명한다.

### ③ 수류탄
- 넓은 공간에 휴면 개체 5마리가 뭉쳐 서 있다.
- G 로 수류탄을 던져 무리를 정리한다.
- 완료 조건: `GrenadeExplodedEvent` 1회 + 무리 전멸. 수류탄이 없으면 2개를 지급한다.

### ④ 보급 (아이템 상자 2종 → 무기 상자) — Q3 확정
| 순서 | 내용 | 완료 조건 |
|---|---|---|
| 1 | 체력이 70% 를 넘으면 "훈련 충격"으로 체력을 50% 까지 낮춘다 (회복 팩을 쓸 이유를 만든다) | — |
| 2 | **회복 팩 상자(청록 `#4DFFD9`) + 수류탄 상자(주황 `#FF731A`)를 같이 투하.** "빛기둥 **색**이 보급 종류다" 안내 + 상자 위 색 라벨 | 투하 |
| 3 | 각 상자의 역할 소개: 청록 = 회복 팩(V, 3초간 회복) · 주황 = 수류탄(G). 두 상자를 F 로 회수 (순서 무관) | `SupplyCollectedEvent` × 2 |
| 4 | V 로 회복 팩 사용 | `PlayerItems.HealEnded` |
| 5 | **무기 상자(보라 `#C8A2FF`) 투하** → 소개: 보라 = 보급 무기. F 로 회수 | `SupplyCollectedEvent` (무기) |
| 6 | 4번 칸 보급 무기로 휴면 개체 무리 처치. 보급 무기 특징 안내: 4번 칸 전용 · 1회용(탄을 다 쓰면 사라지고 들던 무기로 돌아감) · 탄창 보충 안 됨 · 무기별 활용법(기존 보급 정보 카드) | 무리 전멸 또는 보급 무기 소진 |

### ⑤ 강화 체험 (구역 도착 → 자동)
| 순서 | 내용 |
|---|---|
| 1 | 강화 구역 트리거에 들어가면 **강화 화면이 자동으로 열린다** (상호작용 없음) |
| 2 | 오퍼레이터: "회수한 생체 자원으로 장비를 개조할 수 있다. 먼저 **리롤**을 눌러 봐라." |
| 3 | 플레이어가 리롤 → **다시 뽑힌 카드가 모두 에픽**(보라 테두리)으로 나온다 |
| 4 | 오퍼레이터: "**에픽** 등급이다. 같은 강화라도 등급이 높을수록 효과가 크다. 하나 골라라." |
| 5 | 구매 → 닫기 → "이번 개조는 테스트용이다. 전장 진입 전에 초기화된다." |

- 재화가 `리롤 비용(5) + 카드 1장 값` 보다 적으면, 화면이 열릴 때 모자란 만큼 채워 준다 (대사 한 줄).
- 강화 화면은 개편된 상점(`UpgradeManager` v3.2: 카드 3장 · 리롤 · 하급/일반/에픽)을 그대로 쓴다.
- **에픽 확정**은 강화 상점에 "다음 리롤 등급 지정" 요청을 하나 추가해 처리한다 (6장 보완점).

### ⑥ 전장 입장
- 강화를 마치면 게이트 앞 차단막이 열린다. "전 과목 통과. 전장 진입을 허가한다."
- 게이트 트리거에 들어가면 페이드아웃 → 완료 기록 → `Monster Player Integration`.

### 공통
- 화면 안내는 세 가지다: **목표 패널(오른쪽 위)**, **오퍼레이터 자막(아래, 음성은 파일이 있으면 재생)**, **키 배지**.
- 20초 동안 진행이 없으면 힌트를 다시 띄운다.
- 구역 사이에는 진행용 차단막(`TutorialGate`, 피해 없음)을 둔다. 과목을 통과하면 열린다.

- 차단막 겉모양 (2차 피드백, QFX Sci-Fi VFX 머티리얼을 `Assets/Data/Tutorial` 로 복사해 사용 — 원본은 그대로):
  - 진행 차단막(`TutorialGate`): **파란 자기장 막** (`QFX/SFX/EnergyWall`, Energy Wall Blue) + 양옆 발생 기둥. 열리면 막이 접히며 사라지고 기둥은 남는다
  - 피해 차단막(`TutorialDamageBarrier`): **붉은 레이저 그리드** — 가로 레이저 선 6줄(0.25~1.75m, HDR 붉은색) + 옅은 붉은 레이저 막(`QFX/SFX/LaserWall`) + 양옆 발사 기둥. 닿으면 그 자리에 불꽃(`PS_AreaProtector_LaserImpact`), 구르며 통과하면 레이저가 꺼진다
- 목적지 표시 (3차 피드백 — 마지막 전장 입구를 찾기 어려웠음):
  - 화면 표식 `TutorialWaypointHud`: 목적지 위 청록 마름모 + 이름 + 거리. 화면 밖·등 뒤면 화면 가장자리에 붙고 화살표가 방향을 가리킨다. 6m 안에서 흐려진다
  - 바닥 표시(고리·빛기둥)는 두지 않는다 — 메뉴 스타일 화면 표식만으로 충분해 제거 (5차 피드백)
  - 표시 시점: ① 목표 지점 · ② 휴면 표적(조준하면 거둠) · ③ 수류탄 무리(터뜨리면 거둠) · ④ 보급 공터 입구 · ⑤ 장비 개조 구역 · ⑥ 전초기지 게이트. 보급 상자는 자체 빛기둥이 있어 표시하지 않는다
  - 통신: Director → HUD 직접 호출(`ShowDestination` / `HideDestination`). 이름 문구는 `TutorialScript` 목표 문구(`wp_*`)
- 화면 디자인 (4차 피드백 — 메인 메뉴와 같은 말, `MainMenuUIBuilder` 색·글꼴):
  - 색: 달빛 흰색(강조) · 청회색(평소) · 붉은 포인트(표식·키 이름). 영문 머리말은 Aldrich(`GameFlowUiSkin.numberFont`), 한글은 NotoSansKR
  - 상자 대신 얇은 선 + 옆으로 옅어지는 어두운 띠(`HorizontalFade` 재사용)
  - 목표: 오른쪽 정렬 `TRAINING 02 / 05` · 붉은 짧은 선 · 과목 이름 · 목표 문구(키 이름만 붉게). 전장 진입은 `DEPLOY`
  - 자막: `OPERATOR`(붉은색) + 양옆 가는 선, 가운데 정렬 본문. 보상: 붉은 점 + `+1`(영문 글꼴) + "생체 자원 · 보유 N"
  - 건너뛰기: "ESC 길게 눌러 건너뛰기" + 오른쪽부터 차오르는 붉은 선
  - 화면 표식: 속이 빈 얇은 마름모 + 붉은 점, 아래로 가는 선, 거리 `032 M`. 화면 밖이면 붉은 꺾쇠(›)
- 자막·목표 패널은 문장 길이에 맞춰 높이가 늘어난다 (두 줄 문장이 줄임표로 잘리던 문제, 3차 피드백)
- 보급 상자 안내는 기존 보급 UI(빛기둥 색·상자 프롬프트·정보 카드)가 맡는다. 튜토리얼 전용 상자 라벨은 두지 않는다 (2차 피드백)
- 건너뛰기: **Esc 를 1.5초 길게** 누른다 (Esc 짧게 = 기존 커서 풀기와 겹치지 않게). 오른쪽 아래에 게이지가 찬다.
- 보급 낙하 위치는 별도 `ISpawnZoneProvider` 대신 `SupplyDropper.Drop(def, 위치)` 를 새로 두어 해결했다 (6장 H).

## 7. 통신 설계 (기준 v0.1)

| 통신 | 방식 | 이유 |
|---|---|---|
| 단계 → 플레이어 상태 읽기 (질주 중 · 조준 중 · 무적 중 · 체력) | **직접 참조로 매 프레임 확인** | 가까운 객체의 지금 상태값이다 |
| 피해 차단막 → 플레이어 | **직접 호출** `IDamageable.TakeDamage` (트리거 접촉) | 요청. 무적이면 기존 코드가 알아서 무시한다 |
| 차단막 결과 → 단계 | **차단막의 C# event** (`Hit` · `Cleared`) | 가까운 객체 관찰. 전역으로 알릴 필요가 없다 |
| 빈 칸 번호 키 → 무기 칸 HUD | **GunSlot 의 C# event** (`EmptySlotSelected`) | 같은 플레이어 안의 가까운 객체 관찰 |
| 구르기 · 회복 완료 | **기존 객체 C# event** (`RollStarted`, `HealEnded`) | 이미 있다 |
| 처치 · 수류탄 폭발 · 보급 획득 · 보급 무기 소진 · 재화 변화 · 강화 구매 | **기존 EventBus 구독** | 이미 발행되는 전역 사실. 새 이벤트를 만들지 않는다 |
| 휴면 개체 소환 · 휴면 지정 | **직접 호출** `IMonsterFactory.Spawn` → `SetDormant(true)` | 요청하고 결과(생성된 몬스터)를 받아야 한다 |
| 보급 투하 (아이템 2종 → 무기) | **직접 호출** `SupplyDropper.Drop(def, 위치)` | 요청·결과(상자 — 위에 색 라벨을 붙인다) |
| 강화 화면 열기 / 닫힘 | **기존 EventBus** (`GameStateChangedEvent(→Reward)` 발행 / `RewardSelectionFinishedEvent` 구독) | 강화 화면이 원래 이 신호로 동작한다 (`KillRewardTester` 선례) |
| 에픽 확정 | **직접 호출** `UpgradeManager.ForceNextRerollGrade(Epic)` | 요청. 튜토리얼만 쓰는 기능이라 전역 이벤트가 필요 없다 |
| 튜토리얼 진행 상황 | **전역 이벤트를 만들지 않는다** | 튜토리얼 밖에 받을 쪽이 없다 |
| 다음 씬 결정 (인트로) | **PlayerPrefs 값 읽기** | 씬을 넘는 저장 값이다 |

## 9. 끝날 때 정리 (상태가 본편으로 새지 않게)

- 게이트를 통과하거나 건너뛰면 아래를 되돌린다:
  - 재화 0
  - 강화 전부 초기화
  - `Time.timeScale = 1`
- 보급 칸·수류탄·회복 팩·입력 잠금은 플레이어에 속한 값이라, 게임 씬의 새 플레이어가 시작값으로 시작한다 (따로 처리하지 않음).
