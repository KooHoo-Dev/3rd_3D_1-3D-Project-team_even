# 사운드 시스템 리팩토링 공유 (팀원용)

> 브랜치 `feat/SoundSystem` · 2026-10-27 · 자세한 설계·결정 기록은 [SoundSystemRefactor.md](SoundSystemRefactor.md)

플레이어·무기·몬스터·보급·UI 소리가 **게임 상황에 맞춰 자동으로** 나오도록 연결했습니다.
다른 파트 코드는 "알림 몇 줄 추가" 수준으로만 건드렸고, 소리를 바꾸고 싶으면 **코드가 아니라 표(TSV)만 고치면** 됩니다.

---

## 1. 한눈에 보기 — 이제 들리는 소리

"클립" 열: **대여** = 비슷한 소리를 임시로 빌려 씀 · **없음** = 소리 파일이 아직 없어 무음

| 분류 | 언제 | 들리는 소리 | 클립 |
|---|---|---|---|
| 플레이어 | 걷기·달리기 | 발소리 (걸은 거리마다 한 번) | 있음 |
| 플레이어 | 점프·착지·사망 | 목소리·착지음 | 있음 |
| 플레이어 | 스태미나 25% 이하 | 숨소리 (60% 회복하면 멈춤) | 있음 |
| 플레이어 | 수류탄 던지기 | 투척음 | 있음 |
| 플레이어 | 독장판 위에서 피해 | 기침 (일반 피격은 아픈 목소리) | 있음 |
| 무기 | 장전 | 시작 → 탄창 끼우기 → 노리쇠 (3단계) | 있음 (일부 대여) |
| 무기 | 빈 탄창으로 쏘기 | 빈 격발음 → 자동 장전 | 있음 |
| 무기 | 로켓·유탄 폭발 | 대형·소형 폭발음 (전에는 수류탄 소리) | 있음 |
| 무기 | 무기 바꾸기 | 교체음 | 대여 |
| 몬스터 | 평소 | 울음 4~10초마다 (상태와 관계없이). **플레이어 15m 안이면 1.5~3.5초마다, 들어오는 순간 곧 한 번** → 공격 전에도 주변 몬스터를 소리로 알 수 있음. 거리·간격은 SoundService 오브젝트의 `GameSoundRouter` 에서 조정 | 있음 |
| 몬스터 | 파르다트록스(기습형)가 15m 안·시야 밖 | 근처에서는 울지 않고, 시야 밖일 때 공격 전 **Vanish 1번** (`MonsterTable.HiddenSfxKey`). 도약 예고음은 그대로 | 있음 |
| 몬스터 | 공격 직전 (예고) | 몬스터별 공격 소리 → 피할 타이밍 신호 (직후 1.5초는 울음 안 냄) | 있음 |
| 몬스터 | 돌진하다 벽에 부딪힘 | 충돌음 + 기절 소리, 기절 동안 조용 | 충돌음 대여 |
| 몬스터 | 독 포격 | 착탄음 + 장판이 있는 동안 반복음 | 있음 |
| 몬스터 | 사망 | 사망음, 울음·이동 소리 멈춤 | 있음 |
| 몬스터 | 도약 착지 | 착지음 | 없음 |
| 보급 | 떨어질 때·주울 때 | 투하음·획득음 | 투하 없음, 획득 대여 |
| UI | 체력 30% 이하 | 경고음 2초마다 | 있음 |
| UI | 강화 구매·게임오버·보스 처치 | 효과음 | 있음 |
| 아나운서 | 라운드 시작·보스 처치·게임오버 | "Fight" · "Victory" · "Game Over" | 있음 |
| 화면 효과 | 강화 선택 화면 | 효과음·몬스터 소리가 먹먹해짐 | — |

보스 소리는 아직 연결 전입니다 (다음 단계, 보스 담당과 함께).

## 2. 빌드 씬에 넣는 방법

사운드가 나오려면 씬마다 아래 순서를 한 번 해 주면 됩니다.

1. **사운드 담당 오브젝트 만들기** — 씬을 열고 상단 메뉴 **Tools → Audio → Create Sound Service** 를 누릅니다.
   - 씬에 `SoundService` 오브젝트가 생기고, 볼륨 믹서(`GameMixer`)까지 자동으로 연결됩니다.
   - **씬마다 1개만** 있으면 됩니다. 이미 있으면 메뉴가 그것을 선택해 줍니다.
2. **플레이어에 소리 붙이기** — 아래 둘 중 하나.
   - (권장, 플레이어 담당) `Scenes/MS/Prefabs/Player.prefab` 에 `PlayerSoundEmitter` 컴포넌트를 하나 추가 → 모든 씬에 한 번에 적용.
   - (지금 당장) 씬의 플레이어를 `Scenes/GU/Prefabs/Player_Sound.prefab` 으로 바꿔 놓기. 원본 Player 를 그대로 따라가는 복사본(Variant)이라 원본이 바뀌면 같이 바뀝니다.
3. **몬스터는 할 일 없음** — 몬스터가 생성될 때 소리 부품이 자동으로 붙습니다. 몬스터 프리팹을 고칠 필요가 없습니다.
4. **무기·보급·UI도 할 일 없음** — 표(TSV)에 적힌 소리가 자동으로 나옵니다.
5. **Build Settings 확인** — 그 씬이 File → Build Settings 의 목록에 들어 있는지 확인합니다. 소리 파일은 `Resources` 폴더에 있어 빌드에 자동으로 포함됩니다.

빌드 전 꼭 확인할 것 (지금은 막혀 있음 → 5장 참고)

- 플레이어가 "몬스터의 목표"로 등록되어 있어야 몬스터가 쫓아옵니다 (플레이어 담당).
- 몬스터에 맞는 판정(Collider)이 있어야 총에 맞고 죽습니다 (몬스터 담당).

옵션 화면을 만들 때 (UI 담당): 볼륨은 `ISoundService.SetVolume(SoundCategory.Bgm, 0.8f)` 처럼 0~1 값으로 넣으면 믹서에 반영됩니다. 카테고리는 `Bgm` · `Sfx` · `Monster` · `Ui` 네 가지입니다.

## 3. 구현 원리 — 소리가 나기까지

방송국에 비유하면 이렇습니다.

```
 [게임에서 일이 일어남]                [누가 듣고 있다가]               [실제로 소리를 냄]

 몬스터가 공격 준비 ─────┐
 플레이어가 점프   ─────┼──▶  소리 부품(Emitter)  ──┐
 총알이 바닥남     ─────┘     몸에 달린 마이크       │
                                                     ├──▶  SoundService  ──▶  GameMixer  ──▶  스피커
 라운드 시작·게임오버 ───▶  GameSoundRouter  ────────┘      음향 감독           볼륨 믹서
 (게임 전체 알림)           교환원                             ▲
                                                               │
                                             SoundTable.tsv (소리 사전: 이름 → 파일·볼륨·거리)
```

| 부품 | 비유 | 하는 일 |
|---|---|---|
| **SoundTable.tsv** | 소리 사전 | `sfx_rifle_cock` 같은 **이름**마다 어떤 파일을, 얼마나 크게, 얼마나 멀리까지 들리게 할지 적어 둔 표. 소리를 바꾸려면 여기만 고치면 됨 |
| **다른 표의 사운드 열** | 주문서 | 무기표·몬스터표 등에 "이 총의 장전음 = `sfx_rifle_mag_in`" 처럼 사전의 이름만 적음 |
| **Emitter (소리 부품)** | 몸에 달린 마이크 | 플레이어·몬스터 몸에 붙어서 "점프했다", "공격 준비한다" 같은 알림을 듣고 소리를 요청. 몬스터는 자동으로 붙음 |
| **GameSoundRouter** | 교환원 | 라운드 시작·게임오버·보급 획득처럼 게임 전체에 퍼지는 알림을 듣고 소리를 요청 |
| **SoundService** | 음향 감독 | 요청을 받아 실제로 재생. 몬스터 100마리가 동시에 울어도 시끄럽지 않게 **가까운 것·중요한 것만** 골라 틀어줌 (동시 재생 40개 제한, 같은 소리 연타 방지, 먼 소리 생략) |
| **GameMixer** | 볼륨 믹서 | 배경음·효과음·몬스터·UI 볼륨을 따로 조절. 강화 화면에서는 효과음을 먹먹하게 |

핵심 규칙 세 가지

1. **다른 파트 코드는 "알림만" 보낸다.** 예: 몬스터 코드는 "공격 준비 시작"만 알리고, 어떤 소리를 낼지는 사운드 쪽이 정함. 그래서 다른 파트가 소리 때문에 코드를 고칠 일이 거의 없음.
2. **소리 선택은 표에서.** 같은 총이라도 표의 이름만 바꾸면 소리가 바뀜. 새 소리 파일이 오면 `SoundTable.tsv` 의 경로 한 줄만 바꾸면 됨.
3. **소리 하나에 재생 경로는 하나.** 같은 소리를 두 곳에서 틀지 않아 겹쳐 들리지 않음.

## 5. 파트별 확인 요청

다른 파트 파일은 **추가 위주로 몇 줄씩만** 고쳤습니다. PR 리뷰 때 아래만 확인 부탁드립니다.

**몬스터 담당**

- [ ] `MonsterController` 에 소리 알림 발행 추가 (공격 단계·기절·도약 착지) — 기존 동작은 그대로
- [ ] `PounceAttack` 착지 지점에서 알림 1줄, `PoisonZone` 피해 종류를 `Status` 로, 독 착탄·장판 소리 몇 줄
- [ ] **몬스터 프리팹 5종에 Collider 가 없음** → 총·폭발이 맞지 않아 죽지 않음. 정식 히트박스 추가 필요 (테스트 씬은 임시 캡슐로 우회 중)
- [ ] 파르다트록스 도약이 막히면 `도약 취소 복구 지점에 몸체가 들어갈 수 없다` 예외가 매 프레임 반복된 적 있음 (가끔 발생)

**플레이어 담당**

- [ ] **`PlayerController` 가 몬스터의 목표(`IPlayerTarget`)로 등록되지 않음** → 실제 플레이어로는 몬스터가 쫓아오지 않음. `OnEnable` 에서 `ServiceLocator.Register<IPlayerTarget>(this)` 필요 (테스트 씬은 임시 컴포넌트로 우회 중)
- [ ] `Player.prefab` 에 `PlayerSoundEmitter` 추가 여부 (2장 2번)

**무기 담당**

- [ ] `Gun` 장전 흐름: 완료(`CompleteReload`)와 취소(`FinishReload`) 분리, 빈 탄창음 1줄
- [ ] 로켓·유탄 폭발음이 표 값 우선 (프리팹 값은 표가 비었을 때만)

**보급 담당**

- [ ] `SupplyDropper` 의 소리 이름을 표(`SupplyTable.DropSfxKey`)에서 읽도록 1줄

**코어 담당**

- [ ] `ISoundService` 기능 추가(볼륨·덕킹·키로 반복 재생), `IMonsterSoundSource` 신설, `DamageKind.Status` (맨 뒤 추가라 기존 값 번호 그대로)

**데이터(공통)**

- [ ] 무기 8개·몬스터 7개의 `PrefabKey` 경로에 실제 프리팹이 없어 로딩 오류 15건 (사운드 작업 전부터 있던 문제)

**에셋 요청**: 배경음(군중·보스), 총알 타격음, 히트마커, 보스 경고음, 보급 투하음, 도약 착지음, 벽 충돌음, 무기 교체음, 보급 획득음

## 6. 테스트 방법

1. 상단 메뉴 **Tools → Audio → Create Sound Test Scene** (이미 있으면 "다시 만들기")
   → `Scenes/GU/SoundIntegrationTest.unity` 가 만들어집니다: 평평한 지형, 점프 상자, 플레이어 뒤 벽, 몬스터 4종, 사운드 담당.
2. 플레이 버튼을 누르고 확인합니다.

| 해 볼 것 | 들려야 하는 소리 |
|---|---|
| 걷기·달리기·점프·상자 위 착지 | 발소리, 점프 목소리, 착지음 |
| 총을 다 쏘고 한 번 더 쏘기 | 빈 격발음 → 장전 3단계 |
| 숫자 키로 무기 바꾸기, 로켓 쏘기 | 교체음, 큰 폭발음 |
